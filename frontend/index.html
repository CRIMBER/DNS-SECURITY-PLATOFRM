Diagnostics Build and model detail — for engineers, not part of the security picture
Every figure on this page is computed by the backend from stored events — nothing is hardcoded. The DNS gateway resolves allowed queries through the configured upstream resolver and returns a deliberate block response for blocked ones; it makes no other outbound connections and never fetches content from a queried domain. The DGA component is a calibrated statistical model (bigram_llr_v1), not a trained classifier, and no accuracy figure is claimed.
